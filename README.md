# Chatroom Aplikacija

**Chatroom aplikacija** je jednostavan program koji simulira rad sobe za ćaskanje (chat room). Projekat je kreiran sa ciljem da omogući korisnicima međusobnu komunikaciju u realnom vremenu.

## Tehnologije
Aplikacija je u potpunosti pisana u programskom jeziku **Python**.

## Zahtevi
Da biste pokrenuli ovu aplikaciju, na vašem računaru morate imati instaliran **Python** (preporučuje se verzija 3.x ili novija).

## Kako pokrenuti aplikaciju

1. **Preuzmite projekat** na svoj računar (klonirajte repozitorijum ili preuzmite ZIP arhivu).
2. **Otvorite terminal** (ili Command Prompt) i pozicionirajte se u direktorijum gde se nalazi projekat.
3. **Pokrenite program** unosom sledeće komande:

```bash
python main.py
```
*(Napomena: Zamenite `main.py` stvarnim imenom glavnog fajla vaše aplikacije ukoliko se zove drugačije).*
